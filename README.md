# 🚁 HeliXpert-HAL

An AI-powered aerospace intelligence and conversational analytics platform for rotary-wing aircraft data, technical documentation, visual inspection, and multi-modal query execution.

---

## 📌 Architecture Overview

HeliXpert-HAL combines modern AI agents with high-performance analytical databases and an interactive aerospace UI:

- **Frontend**: Next.js 15, React 19, TypeScript, Tailwind CSS, Lucide icons, Three.js landing scene.
- **Backend**: FastAPI (Python 3.10+), DuckDB for lightning-fast OLAP queries, SQLAlchemy & SQLite/PostgreSQL for conversation & metadata storage.
- **AI Core**: Google Gemini & LLM agents for:
  - Text-to-SQL generation and validation
  - Helicopter fleet dataset analytics
  - Vision inspection & aerospace part identification
  - Voice query synthesis and transcription
  - Dynamic interactive chart suggestions

## 🚀 Quickstart Guide

### 1. Backend Setup

```bash
cd backend
python -m venv venv

# Windows:
.\venv\Scripts\activate
# macOS/Linux:
# source venv/bin/activate

pip install -r requirements.txt
```

Configure your environment variables:
```bash
cp .env.example .env
# Edit .env and supply your GEMINI_API_KEY or OPENAI_API_KEY
```

Start the FastAPI backend server:
```bash
uvicorn app.main:app --reload --port 8000
```
Backend API docs will be accessible at: `http://localhost:8000/docs`

---

### 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

The application will be running at: `http://localhost:3000`

---

## 🛡️ Security & Privacy
- Sensitive files (`.env`, local database binaries, and uploaded transient data) are excluded via `.gitignore`.
- SQL queries generated by AI agents undergo strict AST validation and read-only sanitization before execution on DuckDB.
